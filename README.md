# Блок 50 — версия для загрузки через браузер GitHub

Готовый HTML-просмотрщик всей исходной модели «Блок 50 (10.11.2026)».

## Важно

НЕ загружайте ZIP-архив на GitHub. НЕ загружайте исходный GLB (263 МБ) или FBX.
В этой версии модель разделена на 10 файлов максимум 8 МиБ каждый.
**Нельзя смешивать** файлы этой версии с четырьмя большими файлами `model.glb.gz.part01`–`part04` старой версии.

## Пошаговая загрузка через сайт GitHub

1. Распакуйте ZIP на компьютер.
2. В репозитории откройте **Add file → Upload files**.
3. Первый коммит: загрузите только `index.html`, `manifest.json`, `.nojekyll`, `README.md`; нажмите **Commit changes**.
4. Следующие коммиты: загружайте **не больше двух** файлов `model.glb.gz.partXX` за один раз и каждый раз нажимайте **Commit changes**. Так один коммит будет включать не более 16 МиБ данных. Если GitHub всё равно выдаёт ту же ошибку — попробуйте **ровно один** `partXX` в каждом коммите.
5. Загружайте части по порядку от `part01` до `part10`. Все файлы должны оказаться **в корне одной ветки** рядом с `index.html`.
6. В GitHub откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, `main`, `/(root)` и сохраните.
7. Ссылка будет: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

Пока не загружены все части, страница покажет ошибку загрузки — это ожидаемо. Не переименовывайте файлы.

Если загрузка через браузер не работает, используйте **GitHub Desktop**, который отправляет файлы через Git (официальный браузерный лимит 25 МиБ на файл там не действует). Скопируйте содержимое распакованной папки в локальный клон, сделайте коммит и **Push origin**.

## Проверка

Полная модель по завершении загрузки соберётся в памяти браузера автоматически из частей (GLB + gzip). Данные модели не изменялись.

- Несжатый GLB: 275,874,468 байт
- Gzip модель: 80,834,857 байт
- SHA-256 GLB: `990d8e3e84bec3343019a91c614878061f5d0ff0a7ff34fc51ae4c9d295b9c80`

Для большой модели понадобится современный браузер, достаточная оперативная и видеопамять.

Внимание: репозиторий PUBLIC означает, что сама 3D-модель тоже станет публичной и доступной для скачивания всем.
